🎮 Number Guessing Game

My First C Programming Project

Welcome to my Number Guessing Game! This is my first project, created using the C programming language.

About the Project

The computer selects a secret number between 1 and 100. The player has to guess the number.

Features

- Guess a number between 1 and 100.
- Get hints if your guess is too high or too low.
- Count the number of attempts.
- Display a congratulatory message when you guess correctly.

Technologies Used

- C Programming
- Visual Studio Code
- GCC Compiler

Concepts Used

- Variables
- printf() and scanf()
- If-else statements
- Do-while loop

How to Run

1. Download the source code.
2. Compile using "gcc NUMBER_GUESSINGGAME.c -o guessing".
3. Run using ".\guessing.exe".
